# Fichiers de l'école (facultatifs)

Pour afficher le fond de carte de Bordeaux, copier ici `affiche_carte.m` et `fond.png`, fournis par l'école et non redistribués.
Sans eux, `tracer_avions` trace les avions sur des axes simples.

Ne pas copier ici les autres fichiers de l'archive (`bit2registre.m`, `cpr2LatLon.m`, `cprNL.m`, `cprMod.m`, fichiers `.p`) : ils masqueraient les versions du dépôt.
